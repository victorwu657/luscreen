## 1. 产品概述 (Product Overview)

LuScreen 是一款专为 Windows 平台打造的**高性能、全功能屏幕创作工具**。它不仅支持高帧率录屏和长截图，更创新性地引入了**手绘风格标注**，让技术文档和演示视频充满温度。无论是软件演示、Bug 汇报、教学课件制作，还是日常灵感捕捉，LuScreen 都能提供流畅、专业的体验。

## 2. 核心功能亮点 (Key Features)

### 🎥 1. 专业级屏幕录制 (Screen Recording)
*   **多模式录制**：支持**全屏录制**与**区域录制**，无论是录制整个桌面还是单一窗口，都能精准把控。
*   **高清高帧率**：最高支持 **4K 60FPS** 录制，采用 H.264 编码，画质清晰流畅，完美适配游戏与高清教程需求。
*   **音画同步**：
    *   **麦克风录制**：支持选择指定麦克风设备，清晰收录解说人声。
    *   **系统内录 (Loopback)**：完美录制电脑内部声音（如会议音频、游戏音效），无需外接设备。
    *   **独立音轨**：录制时生成独立音频文件，支持后期单独调节人声与背景音量。
*   **摄像头画中画 (Facecam)**：
    *   支持圆形/方形摄像头悬浮窗。
    *   可随意拖拽位置，调整大小。
    *   支持**边框显示**，增强画面层次感。
*   **鼠标特效**：
    *   **点击波纹**：鼠标点击时显示波纹扩散效果。
    *   **高亮光圈**：鼠标周围显示半透明高亮光圈，引导观众视线。
    *   支持自定义光圈颜色、大小及点击效果。
*   **悬浮控制条**：极简设计的录制控制条，支持暂停/继续、停止录制、显示录制时长，不干扰画面内容。

### ✂️ 2. 智能截图与标注 (Screenshot & Annotation)
*   **多样化截图**：
    *   **区域截图**：自由框选截图区域。
    *   **全屏截图**：一键捕捉整个屏幕。
    *   **滚动长截图**：智能识别滚动窗口，自动拼接生成长图，轻松截取长网页或聊天记录。
*   **手绘风格编辑器 (Hand-drawn Style)**：
    *   **一键切换**：独家支持将直线、矩形、箭头实时转化为 *Excalidraw* 风格的手绘草图，让标注更具亲和力。
    *   **丰富工具**：矩形、圆形、箭头、直线、画笔、马赛克。
    *   **智能文本**：支持**多行文本输入**，自动换行，支持大/中/小三档字号，输入体验流畅。
    *   **对象级编辑**：所有标注元素（形状、文字）均为独立对象，支持二次移动、修改、撤销与删除，告别“一笔画错全盘重来”。
*   **精准控制**：
    *   **比例约束**：矩形绘制支持 1:1, 4:3, 16:9 等常用比例。
    *   **数值显示**：实时显示线条粗细数值。
    *   **无损剪裁**：支持对截图进行自由比例或固定比例的二次剪裁。

### 🔍 3. 实用辅助功能
*   **OCR 文字识别**：截图后一键识别图中文字，支持复制到剪贴板，快速提取信息。
*   **独立画板模式**：不仅能编辑截图，还能直接打开本地图片文件进行标注和处理。
*   **全局快捷键**：
    *   `Ctrl+F1`：开始录制
    *   `Ctrl+F2`：暂停/继续录制
    *   `Ctrl+F3`：停止录制
    *   `Ctrl+L`：呼出主菜单
    *   支持用户自定义快捷键，适应个人习惯。

## 3. 技术参数与性能 (Specs)
*   **操作系统**：Windows 10 / 11 (64-bit)
*   **视频格式**：MP4 (H.264 / AAC)
*   **截图格式**：PNG (无损)
*   **性能优化**：
    *   支持 NVIDIA GPU 硬件加速编码（需显卡支持）pro用户。
    *   低资源占用，录制时对系统性能影响极小。
    *   针对高 DPI 屏幕（2K/4K）进行了缩放适配，界面清晰不模糊。

## 5. 快速上手指南 (Quick Start)
1.  **启动**：双击桌面图标或右下角托盘图标。
2.  **录屏**：点击托盘菜单“录制屏幕”或使用快捷键 `Ctrl+F1`，框选区域后点击开始。
3.  **截图**：点击托盘菜单“区域截图”，框选完成后自动进入编辑器。
4.  **设置**：在主界面或托盘菜单中进入设置，调节画质、音频源及快捷键。

## 6. 字幕生成（WhisperX）下载说明

- 默认分发 **CPU 版安装包**，所有机器都可生成字幕（速度取决于 CPU 性能）。
- 若电脑具备 NVIDIA GPU 且希望加速字幕生成，请下载 **GPU 版安装包**（单独提供下载地址）。
- WhisperX 本地模型不随安装包分发：首次使用可能会自动下载模型文件；也可以将模型放入 `models/whisperx/whisper` 以离线使用。
- 相关说明见仓库文档：docs/gpu_subtitle_setup.md
