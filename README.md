## 1. 产品概述 (Product Overview)

LuScreen 是一款专为 Windows 平台打造的**高性能、全功能屏幕创作工具**。它不仅支持高帧率录屏和长截图，更创新性地引入了**手绘风格标注**，让技术文档和演示视频充满温度。无论是软件演示、Bug 汇报、教学课件制作，还是日常灵感捕捉，LuScreen 都能提供流畅、专业的体验。

## 2. 核心功能亮点 (Key Features)

### ✂️ 功能1：截图
*   **多种截图方式**：支持**区域截图**、**全屏截图**与**窗口捕捉**，适合快速截取桌面、应用窗口或指定范围内容。
*   **滚动长截图**：自动识别滚动窗口并拼接成长图，适合网页、文档、聊天记录等长内容保存。
*   **像素级辅助截图**：配合放大镜辅助观察，提升边界选择与细节捕捉的准确度。
*   **后续编辑更顺畅**：截图后可直接进入编辑流程，适合问题反馈、文档说明、内容整理等场景。

### 🎥 功能2：视频录制
*   **多模式录制**：支持**全屏录制**与**区域录制**，无论是录制整个桌面还是单一窗口，都能精准把控。
*   **高清高帧率**：最高支持 **4K 60FPS** 录制，采用 H.264 编码，适合游戏高光、软件演示与高清教程场景，尽可能保留画面细节。
*   **音画同步**：
    *   **麦克风录制**：支持选择指定麦克风设备，清晰收录解说人声。
    *   **系统内录 (Loopback)**：完美录制电脑内部声音（如会议音频、游戏音效），无需外接设备。
    *   **独立音轨**：录制时生成独立音频文件，支持后期单独调节人声与背景音量。
*   **摄像头画中画 (Facecam)**：
    *   支持圆形/方形摄像头悬浮窗。
    *   可随意拖拽位置，调整大小。
    *   支持**边框显示**，增强画面层次感。
*   **鼠标特效与悬浮控制**：
    *   **点击波纹**：鼠标点击时显示波纹扩散效果。
    *   **高亮光圈**：鼠标周围显示半透明高亮光圈，引导观众视线。
    *   支持暂停/继续、停止录制、显示录制时长，不干扰画面内容。
*   **适合教学与演示**：配合画中画、鼠标特效与快捷控制，更适合录制教学课件、产品演示、远程协作说明等内容。

### 🔍 功能3：OCR截图识字
*   **截图后一键识别文字**：可快速提取图片中的中英文文本内容。
*   **适合办公与排错**：适合提取报错信息、代码片段、文档内容、聊天记录中的文字信息。
*   **结果可快速复用**：识别后的内容支持复制到剪贴板，减少手动输入与整理成本。

### 🎨 功能4：智能画板
*   **手绘风格编辑器**：支持将直线、矩形、箭头实时转化为 *Excalidraw* 风格手绘效果，让标注更有亲和力。
*   **丰富标注工具**：包含矩形、圆形、箭头、直线、画笔、马赛克等常用工具。
*   **智能文本输入**：支持多行文本、自动换行与多档字号，适合截图讲解和重点标注。
*   **对象级编辑**：所有标注元素均为独立对象，支持移动、修改、撤销与删除，方便反复调整。
*   **独立画板模式**：不仅能编辑截图，还能直接打开本地图片进行标注和处理，随时记录想法与创意。
*   **精准控制**：支持比例约束、线条粗细数值显示与无损剪裁，方便产出更规范的示意图。

### 📋 功能5：剪贴板
*   **智能剪贴板历史**：自动保存复制过的文字与图片，方便回看和复用。
*   **搜索与一键粘贴**：支持历史回溯、关键词查找与快速粘贴，适合高频跨应用复制场景。
*   **本地优先的数据安全**：剪贴板历史仅保存在本地电脑，兼顾效率与隐私。

## 3. 技术参数与性能 (Specs)
*   **操作系统**：Windows 10 / 11 (64-bit)
*   **视频格式**：MP4 (H.264 / AAC)
*   **截图格式**：PNG (无损)
*   **性能优化**：
    *   支持 NVIDIA GPU 硬件加速编码（需显卡支持）pro用户。
    *   低资源占用，录制时对系统性能影响极小。
    *   针对高 DPI 屏幕（2K/4K）进行了缩放适配，界面清晰不模糊。

## 4. 快速上手指南 (Quick Start)
1.  **启动**：双击桌面图标或右下角托盘图标。
2.  **录屏**：点击托盘菜单“录制屏幕”或使用快捷键 `Ctrl+F1`，框选区域后点击开始。
3.  **截图**：点击托盘菜单“区域截图”，框选完成后自动进入编辑器。
4.  **设置**：在主界面或托盘菜单中进入设置，调节画质、音频源及快捷键。

常用快捷键：

- `Ctrl+F1`：开始录制
- `Ctrl+F2`：暂停/继续录制
- `Ctrl+F3`：停止录制
- `Ctrl+L`：呼出主菜单
- 支持用户自定义快捷键，适应个人习惯。

## 5. 字幕生成（WhisperX）下载说明

- 默认分发 **CPU 版安装包**，所有机器都可生成字幕（速度取决于 CPU 性能）。
- 若电脑具备 NVIDIA GPU 且希望加速字幕生成，请下载 **GPU 版安装包**（单独提供下载地址）。
- WhisperX 本地模型不随安装包分发：首次使用可能会自动下载模型文件；也可以将模型放入 `models/whisperx/whisper` 以离线使用。
- 相关说明见仓库文档：docs/gpu_subtitle_setup.md
