# GitHub 仓库设置（手动步骤）

以下步骤需要在 GitHub 网页端完成（仓库管理员权限）。

## 1) 确认 License 自动识别

1. 确保仓库根目录存在 `LICENSE`（本仓库已添加 AGPL-3.0-only 正文）
2. 打开仓库首页右侧栏，确认出现 License 摘要（GitHub 会自动识别）

## 2) 设置 Topics

1. 打开仓库首页
2. 在 About 区域点击齿轮图标（Edit repository details）
3. 在 Topics 中添加以下标签：

- `agpl`
- `open-source`
- `personal-free`
- `enterprise-commercial`

4. 保存后刷新仓库首页确认生效
