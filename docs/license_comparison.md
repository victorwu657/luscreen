# LuScreen 许可证候选对比（评分表）

评分维度（1-5 分，5 分为最符合）：

1) 个人免费 / 企业收费：是否天然支持“个人免费、企业闭源商用需另购商业授权”的商业模型
2) 强制开源二次分发：是否具有明确的“传染性/同许可”条款与对应源代码义务
3) 法律风险：条款清晰度、兼容性与潜在争议风险（分数越高风险越低）
4) 社区接受度：是否被 OSI/社区广泛接受、生态兼容情况

候选许可证信息来源：

- AGPL-3.0：GNU 官方文本 https://www.gnu.org/licenses/agpl-3.0.html
- SSPL-1.0：MongoDB 官方文本与 FAQ https://www.mongodb.com/legal/licensing/server-side-public-license
- Elastic License 2.0：Elastic 官方 FAQ https://www.elastic.co/licensing/elastic-license/faq
- BSL 1.1：MariaDB 官方文本 https://mariadb.com/bsl11/

## 评分说明（简要）

### AGPL-3.0-only

- 个人免费/企业收费：AGPL 不区分个人/企业，企业也可免费使用；但可以通过“AGPL + 商业授权豁免”的双许可模式实现“企业闭源商用付费”。
- 强制开源二次分发：强 copyleft；并且对网络提供服务的修改版也要求提供对应源代码。

### SSPL-1.0

- 个人免费/企业收费：对“把软件作为服务提供给第三方”场景有更强约束，但对一般企业内部使用并不必然收费。
- 强制开源二次分发：非常强，但触发条件与范围更激进（可能要求开源整个服务栈），争议更大。

### Elastic License 2.0

- 个人免费/企业收费：可免费使用/修改/再分发，但限制托管服务与绕过 license key 等；适合“源代码可见 + 保护商业分发”的模型。
- 强制开源二次分发：不是 copyleft，不要求二次分发必须开源。

### BSL 1.1

- 个人免费/企业收费：非常贴合“生产用途需商业授权”的模型（可通过 Additional Use Grant 放开部分个人使用）。
- 强制开源二次分发：更接近“源代码可见”模型；并不天然等同于 GPL/AGPL 的对应源代码义务体系。
