# 产品设计书：LuScreen (Windows版极简录屏工具)
## 1. 项目概述
LuScreen 是一款运行于 Windows 11 平台的高性能、轻量级屏幕录制工具。 核心理念 ：极简交互、即开即用。参考 macOS 上 CleanShot X 的优雅体验，提供无干扰的录制流程，支持摄像头画中画、系统内录及多比例裁剪。

## 2. 核心功能规格 (Functional Specifications)
### 2.1 录制模式
- 全屏录制 ：一键捕获整个桌面环境。
- 区域录制 (自定义尺寸) ：
  - 用户通过鼠标拖拽框选录制区域。
  - 支持拖拽边缘调整大小，中心拖拽移动位置。
  - 像素级微调 ：提供放大镜效果，辅助精确截取。
- 比例预设 (Aspect Ratio) ：
  - 在选区工具栏提供快捷比例锁定：
    - 16:9 (标准横屏视频)
    - 9:16 (抖音/TikTok/Shorts 竖屏)
    - 4:3 (传统显示器/iPad)
    - 1:1 (Instagram/社交媒体)
### 2.2 视频源与画中画 (Webcam Overlay)
- 摄像头调用 ：自动识别已连接的摄像头设备。
- 画中画 (PIP) 样式 ：
  - 形状 ：支持 圆形 (默认) 和 矩形 切换。
  - 交互 ：摄像头窗口可随意拖拽至屏幕任意位置，不遮挡关键内容。
  - 缩放 ：支持通过滚轮或边缘缩放摄像头画面大小。
  - 镜像 ：支持水平镜像翻转（像照镜子一样）。
### 2.3 音频处理 (Audio Mixer)
- 双通道录制 ：
  - 麦克风 (Input) ：录制解说人声。
  - 系统音频 (Loopback) ：录制电脑内部声音（会议、游戏音效、视频声音）。
- 独立开关 ：用户可以在录制前或录制中独立开启/关闭麦克风或系统声音。
### 2.4 输出格式
- 封装格式 ： .mp4
- 编码标准 ：H.264 (AVC) - 保证最大的兼容性。
- 帧率 ：默认为 30fps，设置中可选 60fps（用于游戏或高流畅度需求）。
### 2.5 交互与显示
- 任务栏/托盘区集成 (System Tray) ：
  - 程序常驻右下角托盘区。
  - 录制计时 ：录制过程中，托盘图标变化或悬浮窗显示 REC 00:00:00 红色计时状态。
- 悬浮控制条 (Floating Bar) ：
  - 录制开始后，显示一个极简的悬浮条（类似于 CleanShot X 或 macOS 的原生录屏条）。
  - 功能包含：暂停/继续、停止、截图、画笔标注（后续迭代）、麦克风开关。
  - 自动隐藏 ：鼠标移开时半透明或缩小，避免干扰画面。
## 3. 用户界面与体验设计 (UI/UX)
由于是 Windows 11 平台，UI 风格将采用 WinUI 3 / Fluent Design 风格（圆角、云母材质背景）。

### 3.1 启动与选区流程
1. 触发 ：双击托盘图标 或 使用全局快捷键（推荐 Alt + S 或 PrintScreen 绑定）。
2. 暗角遮罩 ：屏幕整体变暗，鼠标变为十字准星。
3. 操作栏 ：屏幕底部居中出现“设置栏”，包含：
   - [全屏] [区域] [窗口]
   - [比例预设]
   - [摄像头开关/设置]
   - [麦克风开关] [系统声音开关]
   - [开始录制 (大红色按钮)]
### 3.2 录制中 (On-Air)
- 屏幕四角或选区边缘显示红色细框，提示正在录制区域。
- 摄像头画面悬浮在最顶层。
- 悬浮计时器显示当前时长和文件大小预估。
### 3.3 录制结束 (Post-Recording)
- 点击停止后，右下角弹出预览缩略图（类似 Windows 截图工具或 CleanShot X）。
- 快速操作菜单 ：
  - 📂 打开文件位置
  - ✂️ 简单修剪 (Trimming - 二期功能)
  - 🗑️ 删除
  - ❌ 关闭
## 4. 技术架构规划 (Technical Stack)
为了实现高性能和原生体验，建议的技术选型如下：

### 方案 A：Python 全能型 (推荐，开发快)
- GUI 框架 : PySide6 (Qt for Python) - 界面美观，支持圆角和复杂交互，跨平台能力强。
- 视频/音频处理 : FFmpeg (通过 ffmpeg-python 调用) - 业内最强视频处理核心。
- 屏幕捕获 : DXGI (Desktop Duplication API) - Windows 上高性能截屏技术，比传统 GDI 快得多。
- 音频捕获 : WASAPI (通过 PyAudio 或 soundcard 库) - 用于录制系统内部声音。
### 方案 B：Electron (前端技术栈)
- 如果希望界面极其酷炫（HTML/CSS），但包体积较大，且处理底层系统音频录制相对复杂。
### 方案 C：C# / .NET (原生性能)
- 框架 : WPF 或 WinUI 3。
- 优势 : 与 Windows 11 融合度最高，性能最好，但开发工作量稍大。
## 5. 开发路线图 (Roadmap)
1. 阶段一 (MVP - 最小可行性产品) ：
   
   - 实现全屏和区域录制。
   - 实现 MP4 H.264 编码保存。
   - 实现麦克风录制。
   - 基础的 UI 框架。
2. 阶段二 (音频与摄像头) ：
   
   - 增加系统声音内录 (Loopback)。
   - 增加摄像头圆形悬浮窗功能。
   - 完善托盘计时显示。
3. 阶段三 (优化与修饰) ：
   
   - 固定比例裁剪功能。
   - UI 美化（Fluent Design）。
   - 快捷键支持。

#商业化阶段产品设计书：LuScreen (Windows版录屏工具)


作为产品经理，LuScreen 的商业化策略应基于 **“Freemium（免费增值）”** 模式。核心原则是：**基础功能做到极致好用以获取用户基数，高级功能解决专业痛点以实现变现。**

鉴于 LuScreen 目前已具备录屏、截图、音画同步、摄像头画中画等核心能力，以下是具体的付费功能建议：

### 1. 核心生产力增强 (针对专业用户/KOL)

*   **💎 4K/60FPS 超清高帧录制 (已部分实现)**
    *   **免费版**: 限制为 1080p，2K/ 30fps。
    *   **付费版**: 解锁 4K 分辨率及 60fps 高帧率录制（这对游戏博主至关重要）。
    *   *技术实现*: 您的代码已经预埋了 `video_quality` 选项，只需加个锁即可。

*   **💎 系统内录音频独立音轨**
    *   **免费版**: 麦克风和系统声音混流成一个音轨。
    *   **付费版**: 导出时保留多音轨（.mp4 或 .mkv），允许用户在后期剪辑时单独调整游戏声音和解说声音的音量。
    *   *价值*: 这是专业剪辑师的刚需。

*   **💎 摄像头高级特效**
    *   **免费版**: 基础圆形/方形画中画。
    *   **付费版**:
        *   **AI 虚拟背景/绿幕抠图**: 实时移除摄像头背景，只保留人像（类似 Zoom/腾讯会议）。
        *   **自定义边框**: 上传用户自己的品牌边框图片。

### 2. 后期与编辑 (针对办公/教育用户)

*   **💎 视频轻剪辑**
    *   **付费版**: 录制完成后，提供一个简易编辑器，支持**修剪（Trim）**、**拼接**、**添加字幕**。
    *   *价值*: 很多用户只需要切掉开头结尾的废话，不想打开庞大的 PR/剪映。


*   **💎 屏幕标注与画笔**
    *   **付费版**: 录制过程中提供实时画笔工具（画圈、箭头、高亮），用于教学演示或代码讲解。

### 3. 品牌与输出 (针对企业用户)


*   **💎 GIF 导出**
    *   **付费版**: 将短视频直接导出为高质量 GIF，方便发微信/钉钉/Slack。

### 4. 商业模式建议

*   **订阅制 (Subscription)**: ¥5/月 或 ¥30/年。降低门槛，确保持续收入。
*   **买断制 (Lifetime)**: ¥99 终身。适合不喜欢订阅的个人用户。

### 下一步技术实施建议

如果要实施这些，您需要引入 **许可证验证模块 (License Manager)**。
1.  **生成机器码**: 基于 CPU/主板序列号生成唯一 ID。
2.  **激活码验证**: 离线或在线验证激活码。
3.  **功能锁 (Feature Flag)**: 在代码中封装 `LicenseManager.check_feature("4k_recording")`。

搭建一个基础的 **LicenseManager (许可证管理器)** 框架，这样您可以随时给特定功能加锁。
